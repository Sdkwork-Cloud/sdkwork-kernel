# SDKWork Kernel: Client & Server Deployment Architecture Plan

## Current State Summary

**What works today:**
- Kernel SPI complete (15+ provider families)
- Business HTTP API (Axum REST, 3 surface prefixes)
- UI shell (React/TypeScript, snapshot-based)
- Plugin adapter framework (7 agent adapters)
- Multi-runtime host (AgentKernelHost)

**Key gaps:**
- No bridge between kernel runtime and HTTP API
- No streaming (SSE/WebSocket) endpoints or clients
- UI is read-only (no task/message submission)
- No Tauri desktop integration
- No server binary crate
- No gRPC service layer

---

## Architecture Evolution Plan

### Phase 1: Kernel-to-API Bridge Layer (Critical)

**Goal:** Connect `AgentRuntime` provider operations to `AgentBusinessService` HTTP endpoints.

**New crate:** `sdkwork-agent-api-bridge`

```
sdkwork-agent-api-bridge/
├── Cargo.toml
├── src/
│   ├── lib.rs
│   ├── bridge.rs          # AgentRuntimeBridge - main integration layer
│   ├── session_bridge.rs  # Session lifecycle via kernel runtime
│   ├── model_bridge.rs    # Model invocations via ModelProvider
│   ├── tool_bridge.rs     # Tool invocations via ToolProvider
│   ├── context_bridge.rs  # Context assembly via ContextProvider
│   └── event_bridge.rs    # Event forwarding from kernel to business layer
```

**Key types:**
```rust
pub struct AgentRuntimeBridge {
    runtime: AgentRuntime,
    business_service: AgentBusinessService,
    event_recorder: EventRecorder,
}

impl AgentRuntimeBridge {
    // Session management
    pub fn create_session(&mut self, config: SessionConfig) -> KernelResult<AgentSession>;
    pub fn send_message(&mut self, session_id: &str, message: String) -> KernelResult<AgentMessage>;
    pub fn get_history(&self, session_id: &str) -> KernelResult<Vec<AgentMessage>>;
    
    // Model invocation
    pub fn invoke_model(&self, request: ModelRequest) -> KernelResult<ModelResponse>;
    pub fn stream_model(&self, request: ModelRequest) -> KernelResult<Vec<ModelStreamChunk>>;
    
    // Tool execution
    pub fn invoke_tool(&self, call: ToolCall) -> KernelResult<ToolResult>;
    pub fn list_tools(&self) -> KernelResult<Vec<ToolDescriptor>>;
    
    // Context assembly
    pub fn collect_context(&self, session_id: &str) -> KernelResult<Vec<ContextFrame>>;
}
```

**Files to modify:**
- `sdkwork-agent-kernel/src/runtime.rs` - Add bridge-friendly accessors
- `sdkwork-agent-business/src/application.rs` - Add kernel integration points

### Phase 3: Expand KernelUiClient Interface (High)

**Goal:** Add write operations to UI client (task submission, session management).

**File:** `sdkwork-kernel-ui/packages/sdkwork-kernel-ui-types/src/index.ts`

**New methods on KernelUiClient:**
```typescript
export interface KernelUiClient {
  // Existing
  loadSnapshot(): Promise<KernelUiSnapshot>;
  decidePermission(id: string, decision: PermissionDecisionValue): Promise<PermissionRequestView>;
  
  // New: Session management
  createSession(config: SessionConfig): Promise<SessionView>;
  getSession(sessionId: string): Promise<SessionView>;
  listSessions(): Promise<SessionView[]>;
  closeSession(sessionId: string): Promise<void>;
  
  // New: Message submission
  sendMessage(sessionId: string, content: string): Promise<MessageView>;
  getMessages(sessionId: string): Promise<MessageView[]>;
  
  // New: Task execution
  submitTask(sessionId: string, instruction: string): Promise<TaskView>;
  getTaskStatus(taskId: string): Promise<TaskView>;
  
  // New: Streaming
  subscribeEvents(sessionId: string, callback: (event: KernelEventView) => void): EventSubscription;
}
```

### Phase 4: Server Binary Crate (High)

**Goal:** Create runnable server binary with config, preflight, health checks.

**New crate:** `sdkwork-agent-server`

```
sdkwork-agent-server/
├── Cargo.toml
├── src/
│   ├── main.rs            # Entry point with config loading
│   ├── config.rs          # Server configuration (env, file, CLI args)
│   ├── preflight.rs       # Startup validation (DB, providers, health)
│   ├── health.rs          # Health check endpoints
│   ├── middleware.rs       # Request context, auth, logging middleware
│   └── shutdown.rs        # Graceful shutdown handling
```

**Cargo.toml dependencies:**
```toml
[dependencies]
sdkwork-agent-kernel = { path = "../sdkwork-agent-kernel" }
sdkwork-code-kernel = { path = "../sdkwork-code-kernel" }
sdkwork-agent-business = { path = "../sdkwork-agent-business", features = ["http-axum"] }
sdkwork-agent-api-bridge = { path = "../sdkwork-agent-api-bridge" }
sdkwork-agent-streaming = { path = "../sdkwork-agent-streaming" }
axum = "0.8"
tokio = { version = "1", features = ["full"] }
tower = "0.5"
tower-http = { version = "0.6", features = ["cors", "trace"] }
serde = { version = "1", features = ["derive"] }
tracing = "0.1"
tracing-subscriber = "0.3"
```

**main.rs structure:**
```rust
#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // 1. Load config
    let config = ServerConfig::from_env()?;
    
    // 2. Preflight checks
    preflight::validate(&config).await?;
    
    // 3. Build kernel runtime
    let runtime = build_kernel_runtime(&config)?;
    
    // 4. Build bridge layer
    let bridge = AgentRuntimeBridge::new(runtime, business_service);
    
    // 5. Build Axum app
    let app = build_app(bridge, &config);
    
    // 6. Start server
    let listener = TcpListener::bind(config.bind_address).await?;
    axum::serve(listener, app)
        .with_graceful_shutdown(shutdown_signal())
        .await?;
    
    Ok(())
}
```

### Phase 6: gRPC Service Layer (Medium)

**New crate:** `sdkwork-agent-grpc`

```
sdkwork-agent-grpc/
├── Cargo.toml
├── proto/
│   ├── agent_service.proto
│   ├── session_service.proto
│   └── model_service.proto
├── src/
│   ├── lib.rs
│   ├── agent_service.rs
│   ├── session_service.rs
│   └── model_service.rs
```

**Proto definitions:**
```protobuf
service AgentService {
  rpc CreateAgent(CreateAgentRequest) returns (AgentResponse);
  rpc GetAgent(GetAgentRequest) returns (AgentResponse);
  rpc ListAgents(ListAgentsRequest) returns (ListAgentsResponse);
}

service SessionService {
  rpc CreateSession(CreateSessionRequest) returns (SessionResponse);
  rpc SendMessage(SendMessageRequest) returns (MessageResponse);
  rpc StreamMessages(StreamMessagesRequest) returns (stream MessageResponse);
}

service ModelService {
  rpc InvokeModel(InvokeModelRequest) returns (ModelResponse);
  rpc StreamModel(StreamModelRequest) returns (stream ModelStreamChunk);
}
```
