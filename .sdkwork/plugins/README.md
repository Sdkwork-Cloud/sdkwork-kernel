# SDKWork Plugins

This directory stores checked-in agent/developer plugins for `sdkwork-kernel`.

Plugins must follow `../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`. Installable plugins must provide `.codex-plugin/plugin.json` and must document contributed skills, tools, apps, scripts, or MCP servers.

Plugins must not vendor unrelated toolchains, generated SDK output, runtime databases, logs, cache, secrets, API keys, private certificates, or user-private files.
