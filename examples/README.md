# Examples Workspace

Purpose: runnable examples, integration examples, sample config references, and SDK/API usage examples for kernel consumers.

Owner: SDKWork kernel maintainers.

Allowed content: safe example projects, example manifests, example fixtures, and documentation-linked snippets that are verified or intentionally marked illustrative.

Forbidden content: production secrets, user-private data, generated SDK transport output, runtime caches, and unreviewed third-party code copies.

Related specs: `../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`, `../sdkwork-specs/DOCUMENTATION_SPEC.md`, `../sdkwork-specs/SDK_SPEC.md`, and `../sdkwork-specs/TEST_SPEC.md`.

Verification: run `node scripts/check-kernel-standards.mjs`; executable examples must document their own test command.
