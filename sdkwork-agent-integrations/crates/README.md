# SDKWork Integration Crates

This directory contains SDKWork-owned adapter and plugin crates for external
agent integrations.

Runtime crates are added only when their public boundary is backed by mapping
documents, provider manifests, policy behavior, and conformance tests.

Implemented crate families:

- `sdkwork-agent-integration-core`
- `sdkwork-agent-integration-rig`

Planned crate families:

- `sdkwork-agent-integration-process`
- `sdkwork-agent-integration-conformance`
- `sdkwork-agent-integration-hermes-agent`
- `sdkwork-agent-integration-openclaw`
- `sdkwork-code-integration-codex`
- `sdkwork-code-integration-claude-code`
- `sdkwork-code-integration-opencode`
- `sdkwork-code-integration-gemini-cli`
