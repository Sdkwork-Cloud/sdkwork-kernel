# SDKWork Plugin Crates

This directory contains SDKWork-owned plugin crates for kernel, agent, code,
foundation, protocol, and external-framework extension points.

Runtime crates are added only when their public boundary is backed by mapping
documents, provider manifests, policy behavior, and conformance tests.

Implemented crate families:

- `sdkwork-agent-plugin-core`
- `sdkwork-agent-provider-rig`
- `sdkwork-kernel-plugin-drive`
- `sdkwork-kernel-plugin-knowledgebase`

Planned crate families:

- `sdkwork-agent-plugin-process`
- `sdkwork-agent-plugin-conformance`
- `sdkwork-agent-plugin-hermes-agent`
- `sdkwork-agent-plugin-openclaw`
- `sdkwork-code-plugin-codex`
- `sdkwork-code-plugin-claude-code`
- `sdkwork-code-plugin-opencode`
- `sdkwork-code-plugin-gemini-cli`
