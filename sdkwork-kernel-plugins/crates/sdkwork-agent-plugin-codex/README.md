# SDKWork Codex Plugin

SDKWork kernel plugin for Codex app-server and CLI-backed code agent runtime.

Select with `SDKWORK_KERNEL_AGENT_PLUGIN=codex` in `sdkwork-agent-server`.

## Verification

```bash
cargo test --manifest-path sdkwork-kernel-plugins/crates/sdkwork-agent-plugin-codex/Cargo.toml
```
