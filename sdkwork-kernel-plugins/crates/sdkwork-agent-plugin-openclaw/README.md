# SDKWork OpenClaw Plugin

SDKWork kernel plugin for OpenClaw gateway-backed general agent runtime.

Select with `SDKWORK_KERNEL_AGENT_PLUGIN=openclaw` in `sdkwork-agent-server`.

## Verification

```bash
cargo test --manifest-path sdkwork-kernel-plugins/crates/sdkwork-agent-plugin-openclaw/Cargo.toml
```
